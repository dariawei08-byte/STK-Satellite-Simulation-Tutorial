项目简介

本仓库记录 STK 12（Systems Tool Kit，系统工具包）的学习过程，主要涉及卫星轨道仿真、传感器建模、可见性分析及卫星星座仿真。

内容以实际操作为主，包含软件界面说明、仿真参数设置、结果分析以及学习过程中遇到的问题。

目前使用版本：STK 12.2
